# 海报处理

文字遮住的原始像素已丢失，修复属于近似恢复。目标是主体保持、文字可编辑、无可读旧字与明显块状修补。

1. 标出中英文、标点、页脚及要独立编辑的分隔符区域，留少量余量，避免覆盖面部。
2. 用宿主图像编辑工具对原图执行“仅去字/分隔符，恢复连贯纹理，保持人物、构图及文字背后原有暗调/渐变，不改变整体曝光”，检查输出比例、场景及脸部。
3. regions.json 是原图像素坐标的矩形列表。执行：
   `python scripts/prepare_background.py --source input.png --edited clean-edit.png --regions regions.json --output clean-background.png`
   仅把已修复区域混回原图，掩码外保持原始像素，声明区域周围有少量羽化边缘；此脚本不包含模型或模糊涂抹算法。
4. 检查 clean-background.png 接缝、残字、纹理，必要时重新图像编辑后组合。明显色块不能算通过。
5. scene.json 用 clean_background 与原生文字/装饰重建。标题保持整段文本框，控制字号、字距和位置；金箔可用原生文字纹理/渐变填充近似。
6. 生成 PPT 后运行 edit-check，渲染删文本框副本检查实际嵌入背景。

无图像编辑工具时可用用户提供的无字底图；都没有就告诉用户。人物与重要细节如被图像工具改变，调整编辑或区域，不接受改脸。
